# Pruebas-UCM

Repositorio privado de prácticas para aprender a gestionar GitHub.

## Objetivos

- Aprender a crear y organizar repositorios.
- Gestionar archivos y documentación.
- Comprender commits, ramas y pull requests.
- Practicar la administración de GitHub.

## Estado

Repositorio de aprendizaje. No contiene código ni datos institucionales.
